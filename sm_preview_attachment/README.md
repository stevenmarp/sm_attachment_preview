# SM Preview Attachment

**Version 18.0.3.0.0** | Odoo 18.0 | LGPL-3

Preview Binary Fields, Attachments & Excel Reports directly in Odoo 18 without downloading files.

## 🚀 Key Features

### 1. Preview Button on Binary Fields
- One-click preview button appears next to Binary fields with files
- Works in both form view and list view
- Supports images, PDFs, Office documents, videos, and more

### 2. Attachment Field Support  
- Preview attachments from Many2Many Binary fields
- Common use cases: employee documents, product attachments, etc.

### 3. PDF Report Preview
- Preview PDF reports before downloading
- Print directly from preview modal
- Works with standard Odoo QWeb PDF reports

### 4. 🆕 Excel Preview Mixin for Wizards
- **NEW!** Preview Excel files generated by wizards before downloading
- Easy-to-use mixin - just inherit and implement 2 methods
- Uses SheetJS library for client-side Excel rendering
- Supports multiple sheets with sheet selector

### 5. Modal Preview
- Clean fullscreen modal viewer
- Download button in header
- Press ESC to close quickly

### 6. Office Document Support
- Preview Word, Excel, PowerPoint files
- Uses Office Online viewer for public URLs
- Google Docs Viewer fallback for private instances

## 🔧 Excel Preview Mixin - Usage Guide

### Quick Start

The `sm.excel.preview.mixin` allows any wizard that generates Excel files to have **Preview** and **Download** buttons with minimal code changes.

### Step 1: Add Dependency

In your module's `__manifest__.py`, add dependency:

```python
{
    'name': 'Your Module',
    'depends': ['sm_preview_attachment'],  # Add this
    ...
}
```

### Step 2: Inherit Mixin in Your Wizard

```python
from odoo import models, fields
from io import BytesIO
import xlsxwriter

class MyReportWizard(models.TransientModel):
    _name = 'my.report.wizard'
    _description = 'My Report Wizard'
    _inherit = ['sm.excel.preview.mixin']  # Add this line

    # Your wizard fields
    date_from = fields.Date('From Date', required=True)
    date_to = fields.Date('To Date', required=True)

    @property
    def _excel_filename(self):
        """Override to set custom filename"""
        return f'My Report {self.date_from} to {self.date_to}.xlsx'

    def _generate_excel_data(self):
        """
        Override this method to generate your Excel file.
        Must return BytesIO object containing the Excel file.
        """
        output = BytesIO()
        workbook = xlsxwriter.Workbook(output, {'in_memory': True})
        worksheet = workbook.add_worksheet('Report')
        
        # Your Excel generation logic here
        worksheet.write('A1', 'Hello World')
        
        workbook.close()
        output.seek(0)
        return output
```

### Step 3: Update View XML

Replace your single "Generate" button with Preview and Download buttons:

```xml
<record id="view_my_report_wizard" model="ir.ui.view">
    <field name="name">my.report.wizard.form</field>
    <field name="model">my.report.wizard</field>
    <field name="arch" type="xml">
        <form string="My Report">
            <group>
                <field name="date_from"/>
                <field name="date_to"/>
            </group>
            <footer>
                <!-- Preview button - shows Excel in modal -->
                <button string="Preview" 
                        type="object" 
                        name="action_preview_excel" 
                        class="btn-secondary" 
                        icon="fa-eye"/>
                <!-- Download button - direct download -->
                <button string="Download" 
                        type="object" 
                        name="action_download_excel" 
                        class="btn-primary" 
                        icon="fa-download"/>
                <button string="Cancel" class="btn-secondary" special="cancel"/>
            </footer>
        </form>
    </field>
</record>
```

### Available Methods from Mixin

| Method | Description |
|--------|-------------|
| `action_preview_excel()` | Generate Excel and show preview modal |
| `action_download_excel()` | Generate Excel and download directly |
| `_excel_filename` | Property - override to set custom filename |
| `_generate_excel_data()` | Method - override to generate Excel (return BytesIO) |

### Complete Example


```python
# -*- coding: utf-8 -*-

from dateutil.relativedelta import relativedelta
from io import BytesIO
import xlsxwriter

class YourReportWizard(models.TransientModel):

        # ... your Excel generation code ...
        
        workbook.close()
        output.seek(0)
        return output
```

## ⚙️ Technical Details

### Dependencies
- `web` (Odoo base web module)

### Python Models
- `sm.excel.preview.mixin` - Abstract model for Excel preview in wizards

### OWL Components Patched
- `BinaryField` - Adds preview button for single file Binary fields
- `Many2ManyBinaryField` - Adds preview buttons for attachment list fields

### JavaScript Features
- PDF report preview via `ir.actions.report` handlers
- Excel preview using SheetJS library (loaded from CDN)
- Client action `sm_excel_preview` for wizard Excel preview

### Compatibility
- ✅ Odoo 18.0 Community Edition
- ✅ Odoo 18.0 Enterprise Edition
- ℹ️ Complements Odoo 18 Enterprise built-in chatter preview

## ⚠️ Notes

### Office Preview
For Office documents (Word, Excel, PowerPoint):
- **Public URLs**: Uses Office Online viewer (view.officeapps.live.com)
- **Private/Localhost**: Shows download modal with Google Docs Viewer option

### Excel Preview (Wizard)
- Uses SheetJS library loaded from CDN: `https://cdn.sheetjs.com/xlsx-0.20.1/package/dist/xlsx.full.min.js`
- Formulas are calculated and displayed as values
- Supports multiple sheets with dropdown selector

## 🔄 Migration from Existing Wizard

If you have an existing wizard with `action_generate_xlsx_report()` method, here's how to migrate:

### Before (Old Way)
```python
class MyWizard(models.TransientModel):
    _name = 'my.wizard'

    def action_generate_xlsx_report(self):
        # ... generate excel ...
        attachment = self.env['ir.attachment'].create({
            'name': 'report.xlsx',
            'datas': base64.b64encode(output.read()),
        })
        return {
            'type': 'ir.actions.act_url',
            'url': f'/web/content/{attachment.id}?download=true',
            'target': 'self',
        }
```

### After (With Mixin)
```python
class MyWizard(models.TransientModel):
    _name = 'my.wizard'
    _inherit = ['sm.excel.preview.mixin']  # Add mixin

    @property
    def _excel_filename(self):
        return 'report.xlsx'

    def _generate_excel_data(self):
        # ... generate excel ...
        # Just return the BytesIO, don't create attachment
        return output

    # Optional: keep old method for backward compatibility
    def action_generate_xlsx_report(self):
        return self.action_download_excel()
```
