📎 SM Preview Attachment

Preview Binary Fields & Attachments directly in Odoo 18

Version 2.0.0
Odoo 18.0 LGPL-3 Community & Enterprise

📖 Overview

SM Preview Attachment adds preview buttons to Binary fields and attachment fields in Odoo 18 forms and list views. Preview images, PDFs, Office documents, videos, and more without downloading files!

✅ Odoo 18 Community & Enterprise

Fully compatible with both Odoo 18 Community and Enterprise editions. This module uses OWL 2 component system.

ℹ️ Complements Built-in Features

Odoo 18+ Enterprise has built-in chatter attachment preview. This module adds preview buttons to Binary fields and Many2Many attachment fields in form/list views - features not included in the built-in preview.

🔧 How It Works

Binary Field Preview

When a Binary field contains a file (e.g., employee photo, product attachment, document), a "Preview" button automatically appears next to the filename. Click to open the file in a modal viewer.

Many2Many Attachment Preview

For Many2Many Binary fields (attachment lists), each attachment row shows a preview button. Supports both form view and list view displays.

Office Document Preview

⚠️ Office Preview Requirements

For Office documents (Word, Excel, PowerPoint), the module uses external services:

  • Public URLs: Uses Office Online viewer (view.officeapps.live.com)
  • Private/Localhost: Shows download modal with option to use Google Docs Viewer

📥 Installation

  1. Download Module Download and extract the sm_preview_attachment folder to your Odoo addons directory.
  2. Update Apps List Go to Apps menu and click "Update Apps List" (requires developer mode).
  3. Install Module Search for "SM Preview Attachment" and click Install.

⚙️ Technical Information

Dependencies

This module only depends on web (base Odoo web module).

OWL Components Patched

  • BinaryField - Adds preview button for single file Binary fields
  • Many2ManyBinaryField - Adds preview buttons for attachment list fields
